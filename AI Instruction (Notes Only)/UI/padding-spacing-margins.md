# Padding, spacing, and margins

- Reuse the established spacing rhythm and shared layout components.
- Avoid arbitrary one-off padding or margin values when an existing spacing
  token or component pattern fits.
- Keep dense operational screens readable, compact, and responsive.
- Preserve the existing layout and spacing unless the requested UI change
  requires adjustment.
- Keep card, table, form, modal, header, and sidebar spacing consistent with
  their shared components.
