# Zoom and responsive behavior

- Do not alter the application's 67% zoom/font-size behavior. **Keep the 67%
  rule untouched.**
- Do not add page-specific zoom transforms or scale hacks to compensate for
  layout problems.
- Check that layouts remain usable at the application's supported viewport
  sizes and browser zoom levels.
- Prefer responsive layout and overflow handling over shrinking text or
  changing global scale.
