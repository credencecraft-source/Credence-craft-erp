# Interaction and accessibility

- Clickable elements must show a pointer cursor; disabled elements must show a
  not-allowed cursor.
- Use semantic controls and preserve keyboard navigation and visible focus.
- Give icon-only buttons accessible labels or tooltips.
- Provide explicit loading, error, empty, disabled, confirmation, and success
  states where relevant.
- Use the shared interaction primitives and preserve established behavior
  unless the task explicitly changes it.
