# Colors and tokens

- Reuse the shared ERP design tokens and theme; do not invent local hex colors,
  unmanaged Tailwind colors, or one-off color treatments.
- Use shared semantic tokens for brand, surface, borders, text, muted text,
  success, warning, error, and informational states.
- Keep active navigation, focus, hover, disabled, and selected states aligned
  with the shared design system.
- Text selection should use the brand highlight color.
- Do not change the global theme or the 67% rule as part of unrelated work.
- Preserve existing colors unless the task explicitly requests a visual change
  or the shared branded component needs a deliberate correction.
