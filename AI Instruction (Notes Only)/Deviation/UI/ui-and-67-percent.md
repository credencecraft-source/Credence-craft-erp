# UI notes compared with active instructions

## Difference 1: exact UI tokens and interactions

**Active rule —** Active instructions require unified shared branding, reuse
of shared UI primitives, dense operational layouts, and accessible controls
and status semantics. They do not specify the exact requested type scale,
cursor rules, selection token, delete icon/confirmation requirements, or
button variant names.

**Notes rule —** UI notes additionally specify exact typography sizes/weights,
cursor states, selection highlight, destructive confirmation/iconography, and
Primary/Secondary/Outline/Ghost/Destructive variants.

**Difference —** These exact values are user-requested notes-only details, not
values stated by the checked active repository files.

## Difference 2: 67% behavior

**Active rule —** The checked active repository instruction files do not
specify a 67% behavior.

**Notes rule —** The notes say to keep the 67% behavior untouched.

**Difference —** This is an explicit user-requested note that is absent from
the checked active repository instructions.
