# Module workflow notes difference

**Active rule —** Active instructions require tracing each module's routes,
services, permissions, lifecycle, schema, and tests; they do not prescribe the
module-by-module business sequences written in these notes.

**Notes rule —** Workflow files add conceptual process sequences, possible
restrictions, and conditions to verify for each module.

**Difference —** Those process examples are notes-only and are not confirmed
active product behavior. Verify them against implementation before relying on
them.
