# Master-data and form-page difference

**Active rule —** The ERP Application Engineer agent requires a simple
confirmed-type Masters index; a separate list page per master with prominent
full-width Add, complete table, and empty state; compact sidebar by default on
create/edit; success navigation to parent list; errors retained on the form;
and no generic tip panels unless requested.

**Notes rule —** The Admin/master-data workflow note covers master validation,
dependencies, permissions, limits, imports, and audit, but not all these exact
page and navigation requirements.

**Difference —** The notes omit the agent's detailed master list/form UI
contract. The active agent file is authoritative for those screens.
